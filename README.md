# RandoK7 — site público

Somente site de suporte, política de privacidade e app-ads.txt. O código do aplicativo Android permanece em um repositório privado separado.

Site principal: https://randok7.github.io/

Política: https://randok7.github.io/privacidade.html

Repositório principal: https://github.com/randok7/randok7.github.io

Este é o único site ativo do RandoK7. A publicação anterior foi desativada; versões antigas do aplicativo podem conter links que não funcionam mais.

Suporte: randok7.suporte@gmail.com

Hospedagem: GitHub Pages, branch main, pasta raiz. Sem dependências de instalação ou scripts de coleta de dados. O arquivo .nojekyll permite servir o conteúdo estático diretamente.

A política atual descreve a versão 0.1.14, sem SDK de anúncios ou compras reais. Atualizar a política e as declarações da loja antes da integração desses serviços.

Não colocar chaves, credenciais, APKs, dados pessoais de usuários ou arquivos do projeto Android neste repositório público.
